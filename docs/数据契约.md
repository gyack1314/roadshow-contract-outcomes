# 原始资料契约

所有资料均为本地合成。JSONL一行一条来源观察，row_id仅标识该观察；同业务ID可以在不同revision、批次或接收位置出现。未写revision的静态目录按文件给定值解释，不隐含线上查询。事实字段中的None为缺少来源值，不是零或否。

金额字段以minor结尾时为该币种最小单位整数；数量、位置、时间的单位以字段后缀和政策说明为准。日期为ISO日期；绝对时刻携带偏移；原始received字段决定可见性，不能仅按发生日期提前使用资料。后续业务修改以相同格式输入，不限定样本编号。

## 业务政策

### scope

scope_id表示可独立验收的业务范围，同id高revision替代有效额但不删除原已验收事实，新增范围必须用新id。signed_month由首次该cooperation合同确认固定；扩围不迁移队列。

### contribution

每scope_revision/活动的贡献为非负金额，任一范围全部活动贡献之和<=该范围净履约基数；未归因=基数减该和。每条声明对scopes×sessions所覆盖的全部贡献之和给闭区间上下界。最高可见revision且confirmed声明有效；withdrawn撤回本声明；不静默丢弃引用失效范围的声明，而列待核实和受影响查询。金额以分计，贡献可保留精确有理数或小数区间，展示舍入不得越过真实边界。

### money

累计验收净额=可见验收金额减引用这些验收的退款；不能将退款扣到未验收范围。任一活动/组的区间端点都是在同一全体约束下各自可能值，不代表所有端点可同时取到。矛盾需给可回查的不相容声明/范围子集，不要求特定优化算法。

### publication

方案包含范围×活动分配、所用资料/声明/范围版本和相关party集合；每一相关方须确认同一方案正文。资料变动后，如果约束、基数及方案正文仍完全相同可以保留该方确认，否则受影响方重新确认；未全部有效确认不能发布。范围高revision不能自动继承旧范围声明，原发布保留并提示当前受影响。

## 资料检查

`python -m unittest discover -s tests -v`只检查资料字节与格式，不是尚未开发业务功能的验收。manifest.json中的摘要对应提交内原始字节，收到后续批次应独立登记来历，不修改旧原始记录。
